Agentic Lung Cancer Research Platform

This application uses an existing CNN model for image classification and then coordinates a lightweight agent workflow to explain the output, summarize educational context, and assemble a research-oriented report. The model prediction is never treated as a definitive diagnosis.

This application provides an AI-generated research/educational analysis based on an image classification model. It is not a medical diagnosis and should not be used to make medical decisions.
